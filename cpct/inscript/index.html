CPCT Hindi Inscript Typing Practice

Practise Devanagari Unicode passages using the Inscript input layout enabled on your computer.

Prepare your Inscript keyboard

  1. Enable Hindi Inscript input in your operating system.
  2. Check the input in a plain text editor before starting a timed test.
  3. Practise short passages and focus on accurate characters, matras and punctuation.
  4. Increase the session duration after your accuracy becomes consistent.

This website checks the Unicode text generated by your system; it does not install or remap the keyboard. You can also explore Remington GAIL practice or the main Hindi Unicode practice page.

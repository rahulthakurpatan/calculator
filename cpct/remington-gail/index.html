CPCT Hindi Remington GAIL Typing Practice

Use this page to practise Hindi Unicode passages while your computer is configured for the Remington GAIL input layout.

Before using Remington GAIL practice

  1. Enable a Hindi Unicode input method that uses Remington GAIL in your operating system.
  2. Open a plain text editor and confirm that typed characters appear as readable Devanagari Unicode text.
  3. Return to the practice area, select the matching layout and begin with a short session.
  4. Review matras, conjuncts, spacing and punctuation in your typed text.

The layout selector on this page is a practice setting only. It does not install or change your computer keyboard. For general Hindi practice, visit Hindi Unicode typing practice; for Inscript, visit Inscript practice.
